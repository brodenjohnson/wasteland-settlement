// WASTELAND DIALOGUE SCRIPT
//
// Format
//   === node_id                      starts a node
//   Name: spoken text                a page of dialogue (Name can be anyone, You is the player)
//   ~ narration text                 a page with no speaker
//   @ effect; effect                 effects that run as the node starts
//   > next_node                      go here after the last page (when there are no choices)
//   * [Tag N] Label => target | if cond | do effect; effect
//
// Tags: Honest, Lie, Mercy, Ruthless, Item, Memory N, Combat N, Exploring N, Gathering N, Crafting N, Fishing N
//   Memory N and the skill tags are checks. The rest are just labels.
// Conditions (join with &, start with ! to negate):
//   flag:name   item:Name   item:Name>=3   quest:id=done|active|none
//   rep.mercy>=2   skill.combat>=3   memory>=2   day>=5   level>=3
// Effects (join with ;):
//   flag:name  unflag:name  rep.mercy+1  rep.trust-1  give:Item x2  take:Item x1  caps:20  xp:30
//   quest:start id  event:name  log:text  toast:text  heal:20  hurt:10  recruit  removeNpc  rumour  end
// Reputation tracks: mercy, trust, listeners, hull, raiders (each from -10 to 10)

// ---------------------------------------------------------------- ECHOES
=== echo_Folded Note
~ A kitchen table. A desk lamp with a failing bulb. Your own hand, steadier than you expected, writing the word "sorry".
~ Somebody is standing behind you and not saying anything. You do not turn around.
~ You finish the sentence. You do not cross it out.

=== echo_Dispatch Slip
~ A loading dock under strip lights. Eleven crates on a trolley, one for each tag.
~ A voice you know says "Collect last." Your own voice says "That's me."
~ Somebody laughs. It is not a happy sound.

=== echo_Pump Ledger
~ The hum of a pump in a concrete room. A woman's hand, older than yours, ticking down a column of numbers.
~ She counts ten, then eleven, then stops and counts again. She does not look up.
~ "One missing," she says. "I know which." You are the one holding the door.

=== echo_Signal Tape
~ A small room, a microphone, a red light. You are speaking and you are not afraid, which frightens you more than anything has yet.
~ "If I'm listening to this," says your voice, "then it worked. Do not trust the radio."
~ Then, in a voice that could be yours or could be hers, very quietly: "That is us. That is the radio."
